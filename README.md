#  ProjectMovies

Это консольное Python-приложение для поиска фильмов в базе данных Sakila и анализа популярных пользовательских запросов.

## Функциональность

- Поиск фильмов по ключевому слову с фильтром по году
- Поиск по жанру и году
- Логирование запросов
- Просмотр топ-10 популярных запросов
- Поддержка сохранения результатов поиска
